# Projeto-app-LOCFAMILY
Uma aplicação desenvolvida para compartilhamento de localização, um projeto de desenvolvimento para estudos. Planos futuro lançamento para uso do publico, destinado a segurança entre familiares. 

DOCUMENTAÇÃO DO PROJETO- (LOCFAMILLY)

Loc Family v1: app de localização para a família

Projeto pessoal criado para aprofundar meus estudos em desenvolvimento web. O app mostra em um mapa, em tempo real, onde cada membro da família está, com uma etiqueta retangular com o nome de cada pessoa.

O que eu construí:
• Back-end em Python com Flask e Socket.IO, para atualizações em tempo real
• Interface em HTML, CSS e JavaScript, com mapa em Leaflet e OpenStreetMap
• Lista de quem está online, com entrada por nome
• Um servidor doméstico caseiro, montado a partir de uma TV box que estava sem uso, rodando com Termux

Documentei a v1 com arquitetura, eventos, limitações e roadmap. Na v2, pretendo trabalhar em salas separadas por família e em uma interface mais aprimorada.

Tecnologias: Python, Flask, Socket.IO, JavaScript, Leaflet, Termux
